# 💼 Job Finder

> Plataforma web para publicação e busca de oportunidades de emprego na área de tecnologia.




### ATENÇÃO: aplicação criada para objetivos acadêmicos. As vagas de emprego, nomes e contatos são fictícios.

---

## 📌 Sobre o Projeto

O **Job Finder** é uma aplicação web desenvolvida para conectar desenvolvedores a vagas de trabalho, com foco em oportunidades Home Office. O projeto permite a visualização de vagas em destaque, busca dinâmica por palavras-chave e cadastro de novas oportunidades.

---

## 🚀 Funcionalidades

-  **Listagem de Vagas:** Exibição das vagas mais recentes cadastradas no sistema.
-  **Filtro de Busca:** Pesquisa em tempo real por título da vaga utilizando consultas com `LIKE` no banco de dados.
-  **Cadastro de Vagas:** Formulário estruturado para inserção de novas oportunidades (Empresa, Cargo, Salário, etc.).
-  **Sinalização de Novas Vagas:** Destaque visual na interface para vagas recém-criadas.

---

## 🛠️ Tecnologias Utilizadas

- **Backend:** Node.js, Express
- **Frontend:** Handlebars (Template Engine), Bootstrap 4 (CDN), CSS3
- **Banco de Dados & ORM:** SQLite3, Sequelize
- **Utilitários:** Body-Parser, Nodemon (Ambiente de Dev)

## 🔧 Como Executar o Projeto

### Pré-requisitos
Antes de começar, você precisará ter instalado em sua máquina:
- [Node.js](https://nodejs.org/) (versão 14 ou superior)
- [Git](https://git-scm.com/)

### Passo a Passo

1. **Clone este repositório:**
   ```bash
        git clone https://github.com/igorcosta110/Job-Finder.git
   ```

2. **Acesse a pasta do projeto:**

    ```
        npm install
    ```
2. **Acesse a pasta do projeto:**

    ```
        npm install
    ```

3. **Execute a aplicação em modo de desenvolvedor:**

    ```
        npm run dev
    ```

4. **Acesse no navegador:**

Abra http://localhost:3000 para ver a aplicação rodando.
